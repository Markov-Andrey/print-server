# Print Server API

## Info

Сервак печати на Python

## 🔐 Headers

Все запросы требуют заголовок:

```
X-Token: <your_token>
```

---

## 📌 Endpoints

### 🖨️ POST /print-svg  
Печать набора SVG по заданным параметрам.

**Параметры:**
- `printer` (str, обяз.) — имя принтера  
- `width` (int, обяз.) — ширина страницы в мм  
- `height` (int, обяз.) — высота страницы в мм  
- `data` (List[str], обяз.) — список SVG в base64  
- `grid` (int, не обяз.) — ячеек по горизонтали (по умолчанию `1`)  
- `gap` (int, не обяз.) — отступ между ячейками в мм (по умолчанию `0`)  
- `padding_x` (int, не обяз.) — горизонтальные отступы, мм (по умолчанию `0`)  
- `padding_y` (int, не обяз.) — вертикальные отступы, мм (по умолчанию `0`)  

---

### 📝 POST /print-doc  
Печать Word-файла (`.doc` / `.docx`).

**Параметры:**
- `printer` (str, обяз.) — имя принтера  
- `filename` (str, обяз.) — имя файла  
- `data` (str, обяз.) — содержимое файла в base64  

---

### 📁 POST /print-file  
Печать любого файла.

**Параметры:**
- `format` (str, обяз.) — расширение (допустимые: `JPG`, `PNG`, `PDF`, `SVG`, `DOCX`, `TXT`, и др.)  
- `printer` (str, обяз.) — имя принтера  
- `filename` (str, обяз.) — имя файла  
- `data` (str, обяз.) — содержимое файла в base64
